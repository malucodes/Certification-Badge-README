# 🎓 Certification Badges for GitHub README

Este repositório reúne **badges de certificações** prontas para adicionar no README do perfil do GitHub.

---

## 💡 Como usar

1. Copie o código da certificação desejada  
2. Cole no README do seu perfil GitHub  
3. Substitua:

- `(link do comprovante)` pelo link do seu certificado

# CONTRIBUTING

Obrigado por considerar contribuir com o projeto **Certification Badge README**.

O objetivo deste repositório é fornecer **badges de certificações prontos para copiar e colar em READMEs do GitHub**.

## O que pode ser contribuído

Contribuições aceitas incluem:

- Novas certificações  
- Correção de links de badges quebrados  
- Atualização de certificações antigas  
- Inclusão de novos provedores de certificação  
- Melhorias na organização das tabelas  

## Estrutura do Badge

Cada certificação deve seguir o formato de tabela do projeto.

Exemplo:

<tr>
      <th width="500px">Certificação</th>
      <th>Código</th>
</tr>

## Regras de Contribuição

Ao contribuir:

- Não altere a estrutura geral do repositório  
- Não reorganize grandes seções sem discussão prévia  
- Não adicione conteúdo fora do escopo do projeto  
- Mantenha o padrão visual das tabelas  

## Processo de Pull Request

1. Faça um fork do repositório  
2. Crie uma nova branch  
3. Adicione ou corrija certificações  
4. Envie um Pull Request com uma descrição clara  

Exemplo de título de PR:

`Add Google Cloud Generative AI Leader badge`

## Importante

Este projeto existe para facilitar a cópia de badges individuais.

A coleção completa **não deve ser copiada ou republicada em outro repositório**.

# CONTRIBUTING

Thank you for considering contributing to **Certification Badge README**.

The purpose of this repository is to provide **copy-paste ready certification badges for GitHub READMEs**.

Accepted contributions include:

- Improvements to table organization

- Do not add content outside the project scope  
- Keep the visual table format consistent

1. Fork the repository
